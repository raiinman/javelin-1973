# Purpose
Original AMC 360-style exterior engine asset, its renders, verification records and a separately identified car bay-fit diagnostic.

# Ownership
- `AMC360_Engine.blend`: the editable engine (stock finish), generated by `../../tools/amc360_engine.py`. Do not hand-edit without moving those edits into the generator.
- `AMC360_BayFit_V10_DIAGNOSTIC.blend`: separately named copy of the user-supplied V10 empty-bay fitting reference with the engine appended at the fit root. This is fit evidence only, not a car checkpoint.
- `renders/`, `verification/`: actual-mesh renders and JSON reports from `../../tools/amc360_engine_review.py`.
- Report, sources and evidence boundaries: `../../docs/amc360-engine.md`.

# Local Contracts
- All geometry, materials and label strokes are original and procedural. No downloaded, traced or purchased meshes, textures, fonts or logos; no reference images in this folder.
- Keep separate named components with mounting pivots, about 30,000 evaluated triangles or fewer, and zero unintended inter-object intersections.
- Fit against the current V10 empty-bay reference (or a newer user-supplied bay), not older repository car checkpoints. Never overwrite the supplied car or infer factory mounts or dimensions from it; car hashes must remain unchanged.
- Label target evidence, text sources, comparable-car evidence and fit assumptions separately. No game-compatibility claim without testing that pipeline.

# Work Guidance
- Regenerate rather than edit binaries. `--finish stock` is the research-backed default; `--finish dressup` is the polished variant. The fit root (0, 1.49, -0.235) is a project-fit value.

# Verification
- `python tools/amc360_engine_review.py check --engine assets/engine-amc360/AMC360_Engine.blend --report assets/engine-amc360/verification/engine_check.json`
- `python tools/amc360_engine_review.py fit --engine ... --car <V10 reference> --out assets/engine-amc360/AMC360_BayFit_V10_DIAGNOSTIC.blend --report ... --renders assets/engine-amc360/renders --rig DSI_Javelin_Mechanical_Rig --actions DSI_Hood_Open DSI_Reference_Combined_1_26`
- Run inside Blender 5.2 or with the `bpy` 5.2.1 module; the fit sections need Pillow.
