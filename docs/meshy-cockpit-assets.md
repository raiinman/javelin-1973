# Meshy cockpit assets

The user requested the steering wheel, dashboard and instrument cluster after accepting the corrected Meshy seat's appearance. One generation per component is retained in ignored `build/meshy-cockpit-trial/`.

Reference inputs were inspected before image preparation: video frames39/42 for the engine-turned driver fascia and original radio, video47 for the horn boss, Druk107/109 for the complete three-spoke wheel and dash arrangement, Druk140 for the passenger dashboard shell, and BaT048 for corroborating dashboard construction. Supplemental automatic consoles are excluded. Three AI-edited transparent component inputs preserve the target's appearance while reconstructing occluded areas; they are not untouched photos or measurements.

- `wheel.glb`: complete black-rimmed three-spoke metal wheel and horn hub.
- `dashboard.glb`: padded shell, receiving recess, passenger face, glovebox, vents and grab handle.
- `cluster.glb`: separate engine-turned driver fascia, three gauge wells, radio, vents and lower switch ledge.
- `Meshy_Cockpit_Assets.blend`: all three raw models with packed textures, organized into separate collections in an exploded review arrangement.
- `cockpit-assets.png`: rendered review of the downloaded 3D models.
- `manifest.json`: input/model hashes, mesh counts, source boundaries and generation settings.
- `*-meshy.jpg`: browser proof of each completed textured result.

Each used Meshy7.1 High Detail Ultra2K, textures on, private, image enhancement/pose/multi-view off. Three submissions cost105 existing Meshy credits (747 to642), with no top-up or subscription purchase. Raw meshes are preserved for reduction and fitting. Inspection transforms are uniform display scales, not factory dimensions or cabin registration. Native integration, steering motion and runtime materials are subsequent work; generation does not establish those checks.
