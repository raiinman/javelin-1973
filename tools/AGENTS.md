# Tools

## Purpose
Generate, validate and install the original car mod.

## Ownership
Python tools executed with Blender or standard Python.

## Local Contracts
- Geometry is authored procedurally here, with no third-party model imports.
- Export models in metres with explicit axes and applied object transforms.
- Installer preserves existing unrelated mods and saves.

## Work Guidance
Use installed Blender 5.2 and Python 3.11. Check current API documentation before unfamiliar calls.

## Verification
Run the validator after each package change. Inspect Blender preview and report game tests separately.
