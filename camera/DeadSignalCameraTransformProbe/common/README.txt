Dead Signal Camera - Image Transform Research
Development-only ordinary mod. No external renderer or installer.
Enable in an isolated debug single-player save, then restart the game completely so its original vertex shader is compiled.
Right-click the world and choose Camera research: image transform. Unpause before enabling.
Enable transform, left-drag to pan, right-drag to rotate and flatten, wheel for native zoom. Buttons provide exact presets. Hold compensates character motion within bounded image pan. Return to game restores borrowed visual values.
This transforms the real rendered world image. Rotation is image roll; tilt flattens the same image. Existing occlusion, missing offscreen surfaces and native picking remain unchanged. The research overlay captures mouse interactions; close it before gameplay.
The transform uses temporary visual shader values only while native search mode is disabled. Native search takes priority. No foraging, weather or binding settings are changed intentionally.
